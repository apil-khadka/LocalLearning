Project status · 30 October 2026

A working software foundation. A school pilot still ahead.

The portal now has a private K–12 book catalog and a dedicated reader, while a separate Kolibri facility is provisioned locally. Retrieval, course imports, and school field acceptance remain open work.

Implemented and checked

What is in the repository now.

“Tested” describes software behavior under the stated setup. It does not mean that a school has approved content or completed a field pilot.

Implemented

Student portal and textbook catalog

Responsive English and Nepali UI, protected staff import, page-aware document text, and local file access. The private prototype catalog now contains 216 CDC PDFs assigned across Kindergarten through Grade 12, plus a cross-grade reference; the book files stay out of this public website. Students can search the catalog, filter by grade and subject, paginate, select titles, and open a book in its own reader screen.

Implemented

Switchable tutor providers

Chat supports local Ollama or an OpenAI-compatible endpoint, and embeddings can be configured independently for Ollama or an OpenAI-compatible endpoint. Tutor answers render Markdown and distinguish sourced answers from no-match explanations. The private catalog is not indexed yet, Qdrant is unconfigured locally, and AI remains off by default.

Implemented

Optional Kolibri service

Compose can run Kolibri separately, and the portal reports its reachability and links to its own learning interface. A local demo facility and admin account are provisioned; Kolibri keeps its own identities and content. No channels or learner accounts have been added yet.

Tested with limits

Retrieval, source labels, and fallback behavior

Tests cover Qdrant storage and filtered retrieval, page metadata, no-match answers, and service failures. A disposable Qdrant test passed earlier; the current local stack has no Qdrant URL configured.

Implemented

Container build, deployment boundaries, and public documentation

Docker Compose, a Makefile, CI, a separate student/staff entry point, and a school-network design are in place. No router configuration has been applied.

Still needs school evidence

Next gates before a pilot.

These checks require configured services, reviewed learning material, or school hardware. They cannot be completed by a passing CI run.

Configure

Prepare

Review channel rights and language, import content, create coach and learner accounts, then verify lessons and progress with teachers. The local facility is ready, but no channels are loaded yet.

What is in the repository now.

“Tested” describes software behavior under the stated setup. It does not mean that a school has approved content or completed a field pilot.

Implemented

Student portal and textbook catalog

Responsive English and Nepali UI, protected staff import, page-aware document text, and local file access. The private prototype catalog now contains 216 CDC PDFs assigned across Kindergarten through Grade 12, plus a cross-grade reference; the book files stay out of this public website. Students can search the catalog, filter by grade and subject, paginate, select titles, and open a book in its own reader screen.

Implemented

Switchable tutor providers

The current local profile uses LM Studio with `phi-4-mini-instruct`; Ollama and OpenAI-compatible providers remain configurable. When embeddings and Qdrant are unavailable, local SQLite FTS5 keyword search can retrieve book passages. A fresh setup still has AI disabled by default.

Implemented

Optional Kolibri service

Compose can run Kolibri separately, and the portal reports its reachability and links to its own learning interface. A local demo facility has one imported PhET Interactive Simulations channel with eight resources. Kolibri keeps its own identities and content; school learner accounts and classes still need setup.

Model probes

Matched Phi-4 comparison: a speed/accuracy trade-off

Across 39 fixed probes, Reasoning Plus scored 30/39 and Mini Instruct scored 25/39. Reasoning Plus scored 12/13 on the grade 5–12 math set, including one correct answer missed by the automatic matcher; Mini Instruct scored 6/13. Mini Instruct was about 27.6 times faster on mean response time, but both models scored only 1/3 on Nepali checks.

The current local app profile retains Mini Instruct for its shorter response time. These one-run probes are not teacher ratings or school deployment approval.

Tested with limits

Retrieval, source labels, and fallback behavior

Tests cover Qdrant storage and filtered retrieval, page metadata, no-match answers, and service failures. The current local tutor uses SQLite FTS5 because no Qdrant URL or embedding provider is configured.

Implemented

Container build, deployment boundaries, and public documentation

Docker Compose, a Makefile, CI, a separate student/staff entry point, and a school-network design are in place. No router configuration has been applied.

Next gates before a pilot.

These checks require configured services, reviewed learning material, or school hardware. They cannot be completed by a passing CI run.

Configure

Expand retrieval with embeddings and Qdrant

Local SQLite FTS5 search is available now. Configure embeddings and Qdrant to add semantic retrieval, then compare its passages against teacher-selected book pages. The current Qdrant URL is blank.

Prepare

Extend Kolibri content and create school roles

One PhET channel with eight resources is available in the local facility. Review additional channel rights and language, then create coach and learner accounts and verify lessons and progress with teachers.

Validate

Test the school network and learner experience

Use target Ubuntu hardware and real phones. Test WAN-off access, staff isolation, capacity, backup restore, power recovery, and fluent Nepali educational quality.
